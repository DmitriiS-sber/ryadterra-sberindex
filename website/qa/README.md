# Проверка сайта

`verify-site.mjs` проверяет соответствие встроенных данных сохранённым расчётам, ссылки на локальные файлы, переключение моделей и метрик, пропуски и координаты SVG, меню и режим уменьшения движения.

```bash
npm --prefix qa install
node qa/verify-site.mjs
```

Это проверка DOM и логики без браузерного движка. Она не подтверждает внешний вид, контраст, адаптивность, работу буфера обмена или публичную доступность.

Перед публикацией нужны проверки в настоящем браузере: ширины 1440/834/390/320 px, увеличение текста 200%, клавиатура, открытие PDF/ZIP/YAML/JSON, копирование команд и режим уменьшения движения. После публикации — открытие HTTPS-адреса в сессии без авторизации и проверка всех перенаправлений. Полный конечный адрес не должен содержать `gpt` или личных идентификаторов автора.
