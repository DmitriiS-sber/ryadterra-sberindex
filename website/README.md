# РядТерра — публичный сайт исследования

Статический сайт на HTML, CSS и JavaScript. Научные данные — версия
05.10.2026; ссылки, инструкции и статус GitHub обновлены 06.10.2026.
Исходный локальный сайт из проверенного выпуска сохранён отдельно.

Опубликован: **https://ryadterra.vercel.app/**. Production Vercel; HTTPS и
доступ без регистрации подтверждены. Выполненные проверки — в `QA.md`.

## Локальный запуск

Из корня репозитория:

```bash
python -m http.server 8000 --directory website/dist
```

Открыть `http://localhost:8000`. Сайт не требует установки аналитических
зависимостей, серверного приложения, API-ключей или внешних шрифтов.
Программные расчёты запускаются отдельно по `docs/RUN.md`.

## Структура

- `dist/index.html` — последовательность выводов, методология и встроенные
  неизменённые данные интерактивных диаграмм;
- `dist/styles.css` — адаптивность, контраст, клавиатурный фокус и уменьшение движения;
- `dist/app.js` — горизонты, метрики, детекторы и два примера из отчёта;
- `dist/assets/results.json` — контрольный снимок сохранённых результатов;
- `dist/downloads/` — отчёт (13 страниц), презентация (14 слайдов, PDF/PPTX),
  независимое заключение от 05.10.2026, исходники, конфигурации и агрегаты;
- `qa/` — проверки DOM, данных и локальных ссылок;
- `vercel.json` — конфигурация статического размещения.

Архив исходников содержит научный код и агрегированные результаты из
первой публикации GitHub. Полная таблица расходов, массивы индивидуальных
прогнозов и исходный `SberIndex_Task2_Project.zip` публично не размещаются.
Два коротких примера на сайте соответствуют примерам в отчёте и служат
интерпретации сигналов, а не выгрузке всей панели.

В отчёте и презентации исправлены только устаревший статус GitHub и описание
публичного состава материалов. Независимое заключение не переписывалось:
исторические замечания о GitHub и зависимостях следует читать вместе с
последующими проверками в `docs/CHECKS_20261006.md`.

## Проверки и размещение

```bash
npm --prefix website/qa ci --ignore-scripts
node website/qa/verify-site.mjs
node --check website/dist/app.js
python website/qa/verify-public.py
```

Для Vercel: проект `ryadterra`, корневая папка `website`, Framework Preset
`Other`, Output Directory `dist`, без команд установки и сборки.
Публикация статическая; автоматический сбор свежих данных не настроен.
Конечный адрес должен быть нейтральным и открываться без авторизации.
Фактический статус публикации и проверок записывается в `QA.md`.
