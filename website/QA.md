## Настоящий браузер

В Chromium опубликованный сайт открыт напрямую по HTTPS. Проверены
смена горизонта и метрики, вкладка реальных сигналов, выбор территории,
базовой модели и детектора, переход ползунка к декабрю с клавиатуры.
Меню открывается Enter, закрывается Escape и возвращает фокус на кнопку;
переход к разделу закрывает меню. Кнопка копирования получает подтверждение
браузерного Clipboard API и показывает «Команды скопированы».

Реальные CSS-окна сайта проверены в iframe того же опубликованного домена:
320/390/834/1440 px при размере корневого шрифта 100% и 200%.
Во всех восьми комбинациях `scrollWidth == clientWidth`, девять строк
моделей отображаются, SVG не содержит NaN/Infinity/undefined.
Это проверка адаптивности браузерной вёрстки, а не запуск на восьми
физических устройствах. Результат: `qa/browser-viewport-results.json`.
Обнаруженное при 200% переполнение подписей, чисел, сеток и подвала исправлено.
Снимок первого экрана: `qa/site-desktop.jpg`.

Основные текстовые элементы измерены по вычисленным стилям браузера:
контраст от 5,34:1 (кнопка) до 9,99:1 (текст доказательств); описание,
подписи и примечания превышают 4,5:1. В полученном журнале нет ошибок,
ссылающихся на код `https://ryadterra.vercel.app/`.

## Границы

- Существующая DOM-проверка моделирует `prefers-reduced-motion: reduce`;
  CSS отключает анимации и плавную прокрутку. Системная настройка движения
  в удалённом браузере не переключалась.
- Среда автоматизации использует отдельный виртуальный буфер обмена:
  попытка Ctrl+V вернула `Browser Use virtual clipboard has no data to paste`.
  Поэтому содержимое системного буфера после успешного вызова Clipboard API
  независимо не подтверждено; сообщение об успехе наблюдалось в интерфейсе.
- Ошибки расширения автоматизации `chrome-extension://...` отделены от
  ошибок кода сайта. Проверка не является полным аудитом WCAG.
- Доступность внешних первоисточников может меняться. Внутренние ссылки,
  файлы, GitHub и HTTPS-адрес проверены; актуальность новой экономической
  выборки и полное переобучение этим тестом не подтверждаются.
