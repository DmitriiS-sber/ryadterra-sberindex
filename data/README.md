# Данные и схемы входов

Источники — СберИндекс и первичные публикации Банка России.
Лицензия выгрузки и производной панели: [CC BY-SA 4.0](raw/data_license.txt).
URL, даты получения и SHA-256 источников сохранены в
[source_manifest.json](../results/source_manifest.json) и
[data_audit.json](../results/data_audit.json).

В GitHub опубликованы описание лицензии и схемы `templates/*.csv` для будущих
публикаций/версий, независимых событий, прогнозов и целей будущего теста.
Схемы содержат только заголовки: это форматы входов, а не реальные события
или новые наблюдения. Они не используются для получения исторических метрик.

Таблицы расходов и индивидуальные прогнозы в эту публикацию не включены.
Весь набор для расчётов находится в `SberIndex_Task2_Project.zip` исходного
архива. Для короткого запуска из GitHub скопируйте `data/processed/` полного
комплекта в этот проект. В папке должны быть `panel.parquet`, `selection.csv`
и `monthly_news_features.csv`. Затем установите `requirements-core.txt`
и выполните `make smoke-lite`.

Альтернатива: `python src/prepare.py` загружает официальные источники,
проверяет закреплённый SHA-256 архива и строит панель и новостные признаки.
При недоступности источника используйте имеющийся полный комплект.
Не заменяйте выгрузку другой версией без документирования изменений.

В полном комплекте панель содержит 2 075 территорий и 24 месяца, заканчиваясь
декабрём 2024. Значения являются оценкой средних месячных номинальных расходов
жителей в рублях. Названия территорий и соответствие ОКТМО не подтверждены.
