# Версия 05.10.2026

Эта копия отделена от полученных файлов. Исторические данные, признаки, параметры прогнозов и 2024 год как просмотренный тест сохранены. Новая версия не объявляет независимым уже использованный тест.

## Выполненные изменения

- `src/asof.py`: порядок пересмотров определяется временем публикации конкретной версии. Воспроизводимый контрпример: значение 100 опубликовано 1 февраля, скачано 1 апреля; значение 200 опубликовано 1 марта, скачано 2 марта. На 2 апреля прежний код выбирал 100, новый выбирает 200. Разные версии с одним временем публикации отклоняются как неоднозначные.
- `src/verify_release.py`: проверки позднего скачивания старой версии, перестановки строк, добавления будущей и ещё не скачанной версии, неизвестной даты, неоднозначного порядка, дубликатов и нарушения временного порядка. Отдельно сверяется фиксация кода.
- `requirements-core.txt`: добавлены непосредственные зависимости scipy, matplotlib и reportlab, необходимые численной диагностике и сборке PDF.
- `Makefile`: разделены `validation-numeric`, `report`, `verify-release`; `validation` выполняет численную часть и сборку отчёта.
- Отчёт объясняет Prophet, MAP-регуляризацию, Ridge, горизонты и различие прогноза и детекции. Удалена ссылка на отсутствовавший PDF валидации. Презентация содержит архитектуру решения. Сайт и скачиваемые файлы относятся к одной версии.
- Старый `prospective_lock.json` сохранён в `configs/archive/`. Новая фиксация относится только к новой копии; будущий тест ещё не зарегистрирован и не оценён.

## Что изменилось в числах

Контрпример выбора пересмотра: 100 → 200. Исторические прогнозы и метрики не исправляются этим изменением, поскольку исторический расчёт не использовал `asof.py` и не содержал реестра пересмотров. Независимый повторный расчёт восьми конфигураций без Chronos ранее подтвердил 194 520 сохранённых прогнозов. Проверка Chronos ограничена сохранёнными прогнозами и доступной документацией.

## Как повторить

Сначала распакуйте полный `SberIndex_Task2_Project.zip`. Команды выполняются из каталога `sberindex_task2`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-core.txt
make validation
```

Это повторение диагностики по сохранённым прогнозам, пересчёт остаточных моделей, детекторов и PDF; это не полное повторное обучение всех девяти конфигураций. Полный эксперимент: `docs/RUN.md`. Проверка без сборки PDF: `make validation-numeric`. Только регрессии исправления: `make verify-release`.

## Ограничения

Расчёты выполнены в доступном подготовленном окружении. Установка абсолютно чистого окружения и загрузка весов Chronos в этой версии не подтверждены. После успешного `make validation` дополнительный импорт локальной сборки pyarrow завершился SIGBUS (код 135); причина не установлена. Это отмечено как ограничение устойчивости текущего окружения, а не замолчано успешным журналом предыдущего запуска. Для переноса нужен повтор в чистом окружении. Точная среда выполнения и журнал находятся в `results/release_environment.json` и `results/release_run_summary.json`.

История доступна только за 2023–2024. Отсутствуют исторические даты публикаций/пересмотров, подтверждённый справочник муниципалитетов, независимые реальные события и новые тестовые наблюдения. Это ограничения доказательств, которые нельзя устранить редактированием кода. 108 сигналов в 54 территориях являются кандидатами на изменения. Выгрузка прогноза на 2025 не является актуальным прогнозом на октябрь 2026.

Сайт проверяется автоматически по данным и DOM; такая проверка не заменяет просмотр в браузерах. Сайт и GitHub-репозиторий не опубликованы, конкурсная заявка не отправлена. Для формальной подачи нужен GitHub-репозиторий с доступным кодом согласно официальному заданию.

Для PDF требуется шрифт DejaVu Sans в `/usr/share/fonts/truetype/dejavu/` (в Debian/Ubuntu пакет `fonts-dejavu-core`). Презентация редактируема; её автоматическая пересборка требует среды Artifact Tool. Численный эксперимент и сборка отчёта не зависят от неё.
