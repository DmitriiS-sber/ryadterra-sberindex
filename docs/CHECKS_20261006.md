Эти проверки выполняются для сборки исходников GitHub. Они не являются новым
полным научным аудитом и не заменяют независимый тест на будущих наблюдениях.

## Выполнено локально

- Архив распакован с проверкой отсутствия абсолютных путей, переходов `..` и символических ссылок.
- Исходники из `SberIndex_Task2_Source.zip` сверены с полным `SberIndex_Task2_Project.zip`: различий нет.
- `make check-source`: синтаксис 20 Python-модулей и девять существующих регрессионных проверок as-of — успешно.
- Все YAML конфигурации загружены штатным `config.load_config`; JSON прочитаны без ошибок.
- SHA-256 научных исходников и двух основных YAML совпадают с сохранённым `configs/prospective_lock.json`.
- По CSV полного входного комплекта подтверждены 2 075 территорий, 24 месяца и 575 пропусков 2024 года; эта панель в GitHub не включена.
- Таблица сигналов полного комплекта содержит 108 строк и 54 уникальных ID территории; индивидуальные сигналы в GitHub не включены.
- Числа MAE в README сверены с `results/validation/forecast_by_horizon.csv`.
- Проверены локальные ссылки Markdown и отсутствие распространённых форматов токенов и приватных ключей в публикуемых текстах.

Научные файлы `src/*.py`, `configs/experiment.yaml`, `configs/validation.yaml`
сохранены без изменений; результаты предыдущего расчёта не пересчитывались.
Новая проверка протокола находится в `results/release_verification.json`.

## Ограничения окружения и проверки

Использованы Linux, Python 3.12.14, предустановленные NumPy 2.3.5,
pandas 2.2.3 и PyYAML 6.0.3. В этом окружении отсутствуют PyArrow и Prophet.

Попытка установки `requirements-core.txt` в новый venv завершилась с кодом 1
на первой зависимости: `No matching distribution found for numpy==2.3.5`
и `from versions: none`. Это результат доступного здесь канала установки;
он не доказывает отсутствия версии во внешнем PyPI. Причина не установлена.
Поэтому чистая установка всего аналитического окружения и `make smoke-lite`
локально не подтверждены. Ошибка SIGBUS при импорте PyArrow в предыдущем
подготовленном окружении описана в `RELEASE_20261005.md`; она здесь не
воспроизведена, поскольку пакет отсутствует.

Полное повторное обучение, Chronos, покрытие интервалов и обнаружение
независимо размеченных реальных шоков на этом этапе не проверялись.

## Автоматические проверки

`.github/workflows/source-checks.yml` содержит две проверки на Python 3.12:
установка минимальных зависимостей с `make check-source` и отдельная установка
`requirements-core.txt` с проверкой импорта основных библиотек. Наличие YAML не означает успешный
запуск CI. Фактический статус доступен на странице
[Actions](https://github.com/DmitriiS-sber/ryadterra-sberindex/actions).

Проверка публикации выполняется после загрузки: сверка дерева и Git blob SHA,
чтение README/кода из `main` и открытие публичной страницы без авторизации.
До выполнения этих действий подготовленную сборку не следует считать
проверенной публичной публикацией.
