# GitHub: опубликованный код и обновления

Репозиторий: https://github.com/DmitriiS-sber/ryadterra-sberindex.
Ветка: `main`. Проект добавляется поверх исходного README с сохранением истории.

```bash
git clone https://github.com/DmitriiS-sber/ryadterra-sberindex.git
cd ryadterra-sberindex
```

Состав публикации описан в корневом README. Веса Chronos, окружения, кэши
и тяжёлые сохранённые прогнозные траектории не входят в эту сборку исходников.
Снимки метрик являются результатами предыдущего расчёта и не подменяют
полноценный повторный запуск. Сырые данные и результаты для `make validation`
есть в полном `SberIndex_Task2_Project.zip` из исходного комплекта.

Перед обновлением выполните `make check-source`; после установки аналитических
зависимостей — `make smoke-lite`. Если меняются научные исходники в `src/`,
`configs/experiment.yaml` или `configs/validation.yaml`, прежняя фиксация
будущего теста становится недействительной. Не заменяйте её незаметно:
сохраните старую версию и документируйте новую фиксацию и основания.

Файлы `docs/RELEASE_20261005.md`, `report/methodology.md`, `report/protocol.md`
и сохранённые манифесты относятся к историческому выпуску. Статус публикации
на 06.10.2026 и следующий этап записаны в `docs/STATUS.md`.
